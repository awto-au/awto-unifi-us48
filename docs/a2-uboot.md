# awto-uboot on a2 (target `us48-a2`, #83)

awto-uboot as the bootloader of unit 1's Cortex-A9, loaded into its carveout by the `us48_a2` remoteproc (mode `uboot`). Build only so far: nothing here has run on the board.

## Scope (Dan 2026-11-15: core CPU/SoC first)
- In: DCC console, local CCU clock (1000 MHz), PL310 L2, A9 global timer, `md`/`mw`/`cpu`/`version`, `bootz`/`bootm` of a preloaded Linux, remoteproc `mode=uboot`.
- Later (Kconfig off, no code removed): xe1 eth driver + `tftp`/`ping`/`dhcp`, unit 1 cold switch init (`bcm_hr2_u1_cold_init`), `cmic`/`schan` commands (`BCM_CMIC`), PVTMON. Re-enable = `CONFIG_BCM_CMIC`, `CONFIG_NET`, `CONFIG_US48_CMIC_ETH` and a DMA region in the DT (host bus address = a2 address - `0x04000000`).

## Memory map (a2 view, hwdb `a2_carveout`/`a2_shared`)
| Item | Value | Source |
|---|---|---|
| Carveout | `0x08000000`, 64 MiB (host DDR `0x04000000` via PAXB OARR_0/OMAP_0) | hwdb `a2_carveout` |
| U-Boot RAM (DT memory) | `0x08000000`-`0x0bf00000` (63 MiB) | carveout minus `a2_shared`, `arch/arm/dts/us48-a2-hwdb.h` generated by `build_uboot.py` |
| `a2_shared` | `0x0bf00000`, 1 MiB | hwdb; not RAM, not mapped, never relocated into |
| TEXT_BASE = load = entry | `0x08000000` | defconfig, checked against hwdb in the build |
| Early stack top | `0x08200000` | defconfig, checked inside RAM |
| Image | raw `u-boot-dtb.bin` (185 KiB), must be below 1 MiB | `tmp/uboot/us48-a2-uboot.bin` |
| Relocation | top of RAM (`gd->ram_top` = `0x0bf00000`), malloc 2 MiB below | `board_get_usable_ram_top` |
| zImage / DTB / initrd | `+0x01000000` (`0x09000000`) / `+0x01f00000` / `+0x02000000` | hwdb `a2_zimage` / `a2_dtb` / `a2_initrd`; as [a2-design.md](a2-design.md) |
- External initrd above ~26 MiB collides with relocated U-Boot at the top of RAM; the built-in initramfs is the supported path.
- DRAM controller `0x60000000`+ is never referenced (stalls a2): no DDR init (`SKIP_LOWLEVEL_INIT`), no bank there.

## Console
- U-Boot `arm_dcc` serial driver (`CONFIG_ARM_DCC`, v2026.07 `drivers/serial/arm_dcc.c`), DT node `serial` (`arm,dcc`), CP14 DBGDTRTX/RX.
- a1 reads it through the `us48_a2` DCC tty (`/dev/ttyA2`, debugfs `dcc_log`); the reader starts before the release.
- DCC `putc` retries forever if nobody drains: the reader must run before the release (`mode=uboot` does that). Output stops while a1 is stopped.

## Devices
| Device | Choice |
|---|---|
| CPU clock | `us48_cpu_switch` (E2 relock, `CPU_REENTRY`), 1000 MHz. a1 `us48_a2` sets `cpu_mhz` (default 1600, #88) before the release: U-Boot sees the target and skips; if the ROM state (fid 2) is found, it relocks itself |
| Timer | A9 global timer `0x19020200`, rate = live ARM/2 (`periph_clk`) |
| L2 | PL310 `0x19022000`, `CONFIG_US48_L2` default y here: invalidate + enable before the D-cache; flush + disable in `cleanup_before_linux`. Not tested at 1000 MHz (`cpu` prints L2 state). Switch off if the board test fails |
| L1 | I+D cache on after relocation (`US48_ICACHE`/`US48_DCACHE`) |
| `reset` | none (prints a message); a1 stops/starts the remoteproc |
| Env | `ENV_IS_NOWHERE`, `bootdelay -1` |

## Never touch
- `0x60000000`-`0x6fffffff` (dead DDR controller, stalls a2).
- `a2_shared` (`0x0bf00000`+): a1 owns it (resource table, trace).
- PCIe RC registers (unit 1 is an endpoint), fans, LM75/I2C, QSPI (unit 0 only), unit 0 anything.
- SP805 `0x18039000`: not armed by this build (`US48_ARM_SP805` off); nothing would feed it.

## Defconfig differences (`uboot-port/configs/us48_a2_defconfig`)
- `US48_A2=y`, `TEXT_BASE=0x08000000`, `NR_DRAM_BANKS=1`, DT `us48-a2`, ident ` us48-a2-<sha>` (`version` prints `awto-uboot ... us48-a2-...`).
- `US48_PCIE`, `US48_FAN`, `US48_ARM_SP805` off; `BCM_CMIC`, `NET`, `WDT`, `SYSRESET`, `SPI`, `MTD` off; `US48_CPU_REENTRY=y`, `US48_L2=y`.
- Shared with unit 0 (same `board.c`, `us48.h`): behaviour switched by these Kconfig symbols, not by target `#ifdef`s.

## Build
- `python3 scripts/build_uboot.py --target us48-a2 [--tree DIR]` -> `tmp/uboot/us48-a2-uboot.bin`; build dir `tmp/uboot-build-a2`; log `tmp/logs/build_uboot.log`.
- `--tree DIR` = private U-Boot worktree (the staging resets the tree, so parallel builds need their own).
- Module: `python3 scripts/build_mainline.py --module-only --build-dir <private dir>`.

## Load (a1)
1. Copy `us48-a2-uboot.bin`, `us48-a2-zImage`, `us48-a2.dtb` to `/lib/firmware` (`scripts/build_a2_linux.py` makes the zImage and DTB).
2. `insmod us48_a2.ko mode=uboot payload=1` (payload optional: preloads zImage + DTB at the DT offsets, no stub boot args).
3. `echo us48-a2-uboot.bin > /sys/class/remoteproc/remoteproc0/firmware`; open `/dev/ttyA20` (or `cat` it); `echo start > .../state`.
4. At `awto-uboot>`: `cpu`, `version`, `md 0x08000000`, then `bootz 0x09000000 - 0x09f00000`.
- Reload: `echo stop`, replace files, `echo start`. a2 reset is the recovery for any hang.
- Image format: raw binary copied to the carveout base, entry = base. No uImage wrapper (a1 does not need the CRC; `mode=uboot` rejects images over 1 MiB).
- `mode=elf` (default) is unchanged.
