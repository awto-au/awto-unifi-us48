# Boot health line + self-test (`us48-health`, `us48-selftest`)

- Issues #35, #18 (field-failure telemetry). Read-only. UNTESTED on the board; host-tested with `scripts/selftest_fixture.py` (real busybox ash under qemu, fake `/proc` + `/sys`).
- Overlay (`mainline/rootfs/overlay`): `/usr/sbin/us48-health`, `/usr/sbin/us48-selftest`, `/etc/rc.d/S88us48-health`, `S90us48-selftest` (both background, never block boot), `/etc/inittab` `::shutdown:` hook (`us48-health --clean`).
- `/etc/us48.conf` is generated by `scripts/build_rootfs.py` (`write_conf`): netdev roles (`NET_MGMT`, `NET_SFP`, `NET_PROBE` = hwdb `role = "unit1_probe"` on unit 1, no hard-coded `ge40`), `RESET_REASON_ADDR`/`CRU_REASON_ADDR` (regdb), `EXPECT_CPU_MHZ` (`CONFIG_US48_CPU_MHZ` in `uboot-port/configs/us48_defconfig`), `IMAGE_ID` (git short hash + build time). Missing hwdb facts fail the build.
- Host: `scripts/health_check.py` (ssh via `lx.py`, history `tmp/health/history.jsonl`, `--dry-run` without a board).

## Health line (once per boot)

- Printed to the console, `logger -t us48-health`, `/run/us48-health.last`, and appended to the RAM record. `us48-health --show` prints a fresh line without touching the record.
- One line, `key=value`, spaces in values replaced by `_`.

| Field | Source | Notes |
|---|---|---|
| `up` | `/proc/uptime` | seconds at print |
| `boot` | RAM record | previous `boot=` + 1; 1 when there is no previous record |
| `cause` | register + record | `wdt`, `pcie`, `reboot` (soft + previous clean), `soft_unclean`, `soft` (soft, no record), `power_on` (register 0, no record), `reg_clear` (register 0, record present) |
| `rst` / `cru` | devmem `0x1803f018` `DMU_PCU_IPROC_RESET_REASON` / `0x1803f014` `DMU_PCU_CRU_RESET_REASON` | bits: IPROC b0 WATCHDOG, b1 IPROC_SOFT_RESET, b2 PCIE_SLAVE (regdb `hr2_regs.tsv`). Plain 32-bit reads; `0x2` after a Linux reboot seen live ([uboot-self-boot.md](uboot-self-boot.md) "Live reads", C). SP805 has no cause register |
| `prev` | RAM record | `clean` (shutdown hook ran), `unclean`, `none` |
| `rec` | `/dev/pmsg0` present | `ram`, `no_pstore` |
| `img` | `/etc/us48.conf` | rootfs build id; `kern` = `uname -r` + build number |
| `uboot` | uImage header name (32 B at +32) of the awto-uboot slot, `kernel0` +0 | U-Boot passes no bootargs and no DT ident |
| `ubcrc` | CRC32 of the exact awto-uboot image (64 B header + data size from the header) | same value as the flash read-back in [autochain.md](autochain.md) |
| `kslot` / `kcrc` / `kdcrc` | uImage header at `kernel0` +2 MiB (absolute `0x2e0000`): name, CRC32 of its 64 B header, `ih_dcrc` field | flash content, not necessarily the running image |
| `jedec` | `/sys/bus/spi/devices/*/spi-nor/jedec_id` | `c22019` = MX25L25635E |
| `pcie` | RC (class `0x0604`) LNKSTA from config space (PCIe cap id `0x10` +0x12; `0x9012` = active, [pcie-bringup.md](pcie-bringup.md)); unit 1 endpoint `14e4:8346` `current_link_speed`/`width` | |
| `die` | thermal zones `die0`, `die1` (PVTMON) | C, `err` when the driver returns -EIO |
| `lm75` | thermal zones `lm75-48..4b` | C |
| `fan` / `fanerr` / `quiet` | `us48_fan` sysfs `wire_level`, `frame_errors`; module param `quiet` | `L<level>/0x<byte0>`; the MSPI is write-only, so this is the last frame the driver saw acked, not a read-back (#18 "byte read-back") |
| `poe` / `fw` | `/sys/bus/i2c/drivers/bcm59111` bound devices; `i2cget -y -f BUS ADDR 0x41` (FW_REV) | `skip(no_bcm59111)` without the driver (not in main yet, `wip/sensors-sfp-21`); `<n>/12`, `fw=0x15:12` = value:count |

Not in the line: PoE invalid-temperature counter (the hwmon driver has none), 53 V rail (#18), memory test (U-Boot).

## Boot record

- No flash area is allowed: `kernel1`, bootsel `0x1ee0000`, `u-boot`, `u-boot-env`, `EEPROM` are off limits (CLAUDE.md); `cfg` (`0x1ef0000`) is stock's own config store (stock rewrites it, [autochain.md](autochain.md)); `shmoo` is DDR training data; `kernel0` slots are test images. A flash write needs Dan's go and a chosen area, so none is written.
- RAM instead: pstore/ramoops, `mainline/0027` (`ramoops@6fc00000`, 1 MiB, pmsg 256 KiB). `us48-health` writes its line to `/dev/pmsg0`; the next boot reads `/sys/fs/pstore/pmsg-ramoops-0` (the previous boot's pmsg, restored by ramoops) for `boot=` and the clean flag. The shutdown hook writes `us48-health clean boot=N`.
- Lost on a power cycle by design. Whether the DDR keeps this region over the DMU soft reset and the SP805 reset is not measured (uboot-1 re-trains the DDR, [uboot-self-boot.md](uboot-self-boot.md)): board test 2. If it does not, `prev=none boot=1` every time and the record is useless; the register `rst=` still works.
- Region choice: above the 64 MiB a2 carveout, 4 MiB below the DDR top (uboot-1 relocates to `0x6ff40000`, [uboot.md](uboot.md)); ramoops also keeps a console log and panic dmesg there.
- Register caveat: the reset-reason bits may accumulate over several resets (no clear is done, nothing is written to them); `cause` therefore also uses the record.

## Self-test (`us48-selftest`)

- One line per check: `PASS|WARN|FAIL name detail`; exit code = FAIL count (summary line excluded). Output: stdout, `/tmp/us48-selftest.log`, `logger -t us48-selftest`. Read-only; host run ~0.6 s under qemu, target < 2 s (board time not measured).
- Boot: `S90us48-selftest` in the background. By hand: `us48-selftest; echo $?`.

| Name | Check | Verdict |
|---|---|---|
| `cpu` | 1 processor, implementer `0x41`, part `0xc09` (MIDR `0x414fc091`, [hardware.md](hardware.md)) | FAIL otherwise |
| `clock` | BogoMIPS / 2 within +-5 % of `EXPECT_CPU_MHZ` (stock: 795 BogoMIPS at 400 MHz, [stock-bootlog-facts.md](stock-bootlog-facts.md)) | FAIL otherwise |
| `mem` | `MemTotal` | PASS >= 150000 kB (256 MiB minus the 64 MiB a2 carveout, minus 1 MiB ramoops); WARN >= 100000 kB; else FAIL |
| `thermal` | LM75 x4 and die0/die1 through the thermal zones | FAIL if a zone is unreadable or outside -20..150 C, fewer than 4 + 2 zones, LM75 >= 80 C or die >= 110 C; WARN LM75 >= 70 C or die >= 100 C |
| `fan` | `us48_fan` `wire_level` >= 0 and `frame_errors` 0 ([fan.md](fan.md)) | FAIL not bound / no frame acked; WARN failed frames since probe |
| `i2c-tree` | `i2c-2..10`, mux `2-0070`, LM75 `9-0048..4b` | FAIL if any missing |
| `poe` | 12 bound `bcm59111` devices | WARN skipped without the driver; FAIL if bound and != 12. Never probes `0x28..0x30` |
| `pcie` | unit 1 endpoint `14e4:8346` enumerated, speed and width reported | FAIL if absent |
| `flash-id` | spi-nor `jedec_id` = `c22019` | FAIL otherwise |
| `mtd` | 7 partitions with the [flash map](hardware.md#flash-map) names | FAIL < 7, WARN on name mismatch |
| `sfp-driver` | 4 bound sockets in `/sys/bus/platform/drivers/sfp` | only reported when the sfp driver exists (`wip/sensors-sfp-21`); FAIL if != 4 |
| `sfp-i2c-3..6` | `i2cdetect -y -r BUS 0x50 0x51` on the cages (front 49..52): module present / absent | PASS either way, FAIL if the bus is missing |
| `module` | `us48_cmic` in `/proc/modules` | FAIL if not |
| `unit0-<mgmt>` | `copper_ready` and `block_ready` of the management netdev (hwdb `role = management`) | FAIL if not 1 |
| `unit1-<sfp>` | SFP+ netdevs (hwdb `xe*`) exist | FAIL if missing |
| `unit1-<probe>` | hwdb `role = "unit1_probe"` copper netdev exists (not opened at boot: `copper_ready` 0 is reported, not judged) | FAIL if missing |

## Limits

- 80 C = LM75 emergency trip of the quiet rule (fans to 100 %), 110 C = die trip, 70 C / 100 C = their hysteresis points ([fan.md](fan.md)).
- No `i2cdetect` on `i2c-0`/`i2c-1`: hangs, pads unrouted ([board.md](board.md#i2c-topology)). The PoE FW_REV read is `i2cget` of one register on a bound device, and only with the driver present.
- `clock` assumes `BogoMIPS = 2 x MHz` (calibrated delay loop, stock 795.44 at ~398 MHz); a timer-based delay would break it: board test 1.
- Not covered: EEPROM, DDR patterns, JSON output, per-step time bounds.
