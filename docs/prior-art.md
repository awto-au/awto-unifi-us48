# Prior art

Survey for #42, 2026-10-14. Sources: GitHub (`gh search repos|code|prs`), grep.app, OpenWrt forum, svanheule.net wiki, DuckDuckGo.
GitLab search needs a login (not covered); Codeberg/sr.ht had no hits. "Last activity" = last push / last post at survey time.

- No open project has working switch ports on any HR2 (BCM5334x) board. Boot-only images exist; nothing past that.
- Closest working analogues: OpenWrt `realtek` target (SoC-integrated switch, DSA, already ships Ubiquiti USW models) and EdgeNOS (Helix4/CMICd on ARM iProc, SDK-based).
- BCM59111 has a GPLv2 Linux driver from Ubiquiti itself (UDM/UNVR kernels), same firmware v21 as the US-48.

## Reuse now (ranked)

1. **udm-kernel `bcm59111.c`** (GPLv2, fw v21) → #26 driver base (port to pse-pd ops, `tps23881` as shape); #23 init table + fw-load protocol + measurement scaling, cross-check against `scripts/poe_msgmap.py`; #24 OP_MOD shut = per-port off, fw-already-loaded check avoids PoE drop on warm reboot.
2. **OpenWrt `realtek` target** → #4 architecture (DSA switch driver + CPU-port eth driver for an SoC-integrated switch); #41 precedent for Ubiquiti switches merged in OpenWrt and pse-pd drivers merged mainline (contacts: jonasjelonek, plappermaul); #19 fan policy from PR #22416.
3. **EdgeNOS + edgecore-5610 RE + ffn_bcm.c** → #4 bring-up order and SDK-free S-channel access (latched-error gotcha, DMA via SCHAN); #30 name-table extraction method; #40 hash-table opcodes for L3 programming (map to HR2 tables via OpenBCM `hurricane2/l3.c`).
4. **unifi-tlsg + unifi-stubd + OpenUniFi + open-omada-device-agent** → #33: switch inform payloads and `port_overrides` mapping (tlsg, MIT), controller test gate (stubd, AGPL: reference only), OpenWrt C agent shape (OpenUniFi), ECSP front-end (open-omada, Apache-2.0).
5. **OpenBCM KNET/BDE (GPL) + OpenMDK `bcm53344`** → #4 interim: OpenMDK init + KNET netdevs gives management Ethernet (milestone 3) before a native driver; plappermaul's `sdk-6.3.2/6.4.1` for era-matched register names (#30 #37).
6. **USW GPL drop on svanheule.net** → fetch into `sources/` and diff against stock 7.5.15 kernel (#10 #27); if it is gen1 bcm5334x, closes the "Ubiquiti GPL not found" gap in `sources.md`.
7. **Forum evidence (posts 2, 55, 61–66)** → #24 #27: stock refuses to boot when PSE init fails; `/proc/iproc-pse/enable` and `/proc/gpio/poe_passthrough` are the stock knobs to mirror.
8. **ubnteeprom** → EEPROM-partition MAC/identity for milestone 3 and #33.
