# hwdb: single source of truth for hardware facts (#72)

- Facts live in `hwdb/*.toml`; code, headers, Ghidra scripts and doc tables are generated from them.
- Loader: `scripts/hwdb.py` (stdlib `tomllib`). The SDK regdb (`regdb/hr2_*.tsv`) is merged in as a bulk source, never converted.
- Step 1 of #72 only: schema, loader, generators, lint, first content. Script/C migration follows in small commits.

## Layout
- `hwdb/soc/*.toml`: spaces, regions, blocks, registers (memmap, clocks, periph, a9, paxb, cmic).
- `hwdb/board/ports.toml`: front-panel port map (52 front + internal HiGig 28/29 on both chips).
- `hwdb/fw/<binary>.toml`: vendor-binary functions (`uboot1`). Restricted TOML subset, see Ghidra round-trip.
- `hwdb/gen/`: generated, committed: `us48_hwdb.h`, `hwdb.rs`, `ghidra_import_hwdb.py`, `ghidra_export_hwdb.py`.
- `docs/hwdb-map.md`: generated tables. `docs/port-map.md`: port table between markers is generated.

## Schema
- Provenance on every fact: `src` (doc section / datasheet page / disassembly PC / SDK file:line / live read + date) and `conf` = `"C"` (confirmed) or `"I"` (inferred). Docs disagree: `conf = "I"` plus `note`.
- Regs inherit `src`/`conf` from their block unless set. Superseded facts are deleted, not annotated.
- `[space.ID]`: `desc`. Spaces: `axi0` (unit 0 AXI/physical as seen by a1), `axi1` (unit 1 AXI as seen by a2), `bar0u1` (unit 1 BAR0 offsets).
- `[region.NAME]`: `space, base, size?, kind (ram|rom|alias|flash|device|pcie|l2lock|window|hazard), unit?, desc, src, conf, note?`.
- `[block.NAME]`: `space, base, size?, unit?, desc, src, conf, like?, note?`. `like = "other"` copies its registers (second instance).
- `[block.NAME.reg.REG]`: `offset` (from block base), `width=32, access=rw, reset?, count=1, stride=width/8, desc, src?, conf?, note?, sdk?`.
  - `fields = ["NAME hi:lo desc", "NAME bit desc"]`, or `[block.N.reg.R.field.F]` with `bits`, `desc`, `enum = {0 = "x"}`.
  - `sdk = "SDK_REG_NAME"`: `check` fails if hwdb address differs from the regdb address (cross-check against the bulk source).
- `[binary.NAME]` (`desc, base, arch`), `[binary.NAME.func.FN]`: `name, addr, size?, role, regs = ["block.REG" | ...], src, conf`; `[[binary.NAME.comment]]`: `addr, kind (eol|pre), text, src, conf`.
- `[[port]]`: `front` (0 = internal), `id, label, unit, logical, phys, phy (gphy|octal|none|higig), phy_bus?, phy_addr?, lane, sdk?, linux?, src, conf`.
- SDK merge (loader): `sdk_iproc` (absolute AXI offsets, regtype iprocreg), `sdk_cmic` (offsets from `cmic0`), S-channel regs/memories in `db.sdk_sbus_regs` / `db.sdk_sbus_mems`.

## Use
- Python: `sys.path.insert(0, scripts dir); import hwdb; hwdb.addr("ccu.POLICY_FREQ")`, `hwdb.default().field("ccu.PLLARMA.PDIV").mask`, `.port(front)`, `.find(0xaddr)`.
- CLI: `python3 scripts/hwdb.py check|stats|addr NAME|find 0xADDR`.
- C: `#include "hwdb/gen/us48_hwdb.h"`: `HW_<BLOCK>_BASE`, `HW_<BLOCK>_<REG>` (offset), `..._<FIELD>_SHIFT/_MASK`, `HW_<REGION>_BASE/_SIZE`. Rust: `hwdb/gen/hwdb.rs`, same names.

## Add a fact
1. Edit the TOML (reg in an existing block, or a new block); give `src` and `conf`; add `sdk =` when the regdb has the register.
2. `python3 scripts/hwdb.py check` (schema + sdk cross-check).
3. `python3 scripts/hwdb_gen.py` and commit the TOML plus generated files. `--check` fails on stale output.

## Validation (#86)
- `hwdb/validation/u1.toml`: per regdb register (`[hw.sdk_iproc]`, `[hw.sdk_cmic]`, key = regdb name, `NAME[i]` for arrays): `hw = {seen, reset_ok, ro_ok, date, unit}`. Generated by `scripts/hwdb_probe.py report`; `rw_ok` is not measured yet (read-only phase).
  - `seen`: the read completed. `false` carries `why` (write-only, read side effect, blocked = stalls the bus, abort + DFSR, not read).
  - `reset_ok`: `((cold ^ regdb reset) & rmask) == 0` on the cold power-on state. `ro_ok`: bits outside `rmask` equal the reset (omitted when `rmask` is all ones).
- `hwdb/validation/u1-values.tsv`: cold and warm (after `us48_cmic_xe` unit 1 init) values, `class` = mismatch cause. `hwdb/validation/u1-blocked.toml`: address ranges whose read stalls a2, never read until the cause is removed.
- Loader: `Db.hw`, `Db.hw_of("block.REG")` (hand reg with `sdk =` maps to its regdb record), `Db.blocked`. Coverage table: `docs/hwdb-map.md` (generated).
- Method (unit 1, a2, read-only):
  1. `python3 scripts/hwdb_cold_image.py`: debug image whose rc scripts load only unit 0 cmic + `us48_pci` (no `us48_cmic_xe`, so unit 1 is not initialised).
  2. `python3 scripts/a2_up.py tmp/mainline/us48-mainline-cold.bin` (power cycle, RAM boot), then per pass `python3 scripts/hwdb_probe.py build [--suspect NAME]` + `run cold`. Passes: main, then each suspect range (`SUSPECT` in the script) and `cmic` in its own run: a hang costs one power cycle, the range goes to `u1-blocked.toml`.
  3. `insmod us48_cmic_xe.ko` (+ `us48_pvtmon.ko` for die temps), same passes with `run warm`. `python3 scripts/hwdb_probe.py report`, `python3 scripts/hwdb_gen.py`.
- a2 side: `a2fw/regprobe.c` (MMU off, strongly ordered, own vectors via VBAR): a data abort is flagged by `rp_dabt`, the load is skipped, the record shows `A` + DFSR. Results in trace0 (192 KiB). Word reads only at aligned addresses; byte reads for unaligned offsets and ChipcommonA UARTs.
- Gap probe (phase 2, `scripts/hwdb_gaps.py`, same a2 firmware): unnamed 4-byte words of the named pages of blocks whose IDM `RESET_CONTROL` reads 0, in 256 B windows, nearest to a named register first. `plan` / `step` (exit 3 = a window hung a2, marked blocked, power cycle, `step` again) / `report`.
  - Output: `hwdb/validation/u1-gaps.tsv` (unnamed addresses that answered non-zero: "undocumented"), `u1-gap-windows.tsv` (every window), hung windows as `gap_*` in `u1-blocked.toml`. Coverage table: `docs/hwdb-map.md`.
  - Blocked entries carry `state` = `in reset` (IDM `RESET_CONTROL` = 1) or `hang`.
- Skipped on purpose: write-only (regdb flag 0x20), FIFO pops, semaphores, interrupt-acknowledge, clear-on-read UART status (`SKIP_NAME` in `scripts/hwdb_probe.py`).

## Validation, unit 0 (#86, read-only from a1)
- Files: `hwdb/validation/u0.toml` (`unit = 0`, same fields), `u0-values.tsv` (columns `uboot`, `linux`), `u0-blocked.toml` (`state` = `mapped` | `in reset` | `hang`, optional `phase`), `u0-vs-u1.tsv` (registers that read differently on the two units, `cause` column; `scripts/hwdb_u0_vs_u1.py`).
- `reset_ok` is against the awto-uboot state (uboot-1 + awto-uboot ran before: a1 cannot read a cold chip); the linux state is the second value column.
- uboot state: `python3 scripts/hwdb_probe.py --unit 0 build` then `python3 scripts/hwdb_probe_u0.py run uboot [--suspect NAME]` at the `awto-uboot>` prompt (`dev.py uboot`, or `hwdb_probe_u0.py prompt` = `reset`).
  - Payload `a1fw/regprobe_u0.c` (+ `_asm.S`, `.ld`): TFTP to 0x01000000, `dcache flush` + `icache flush`, `go`. Own vectors (VBAR), data abort flagged and skipped, UART1 stream of 8-hex tokens; a stalled read = output stops (hang bound 1 s).
  - Not `dcache off/on`: `on` rebuilds the page table and drops the uncached DMA regions of the eth driver (TFTP then fails).
- linux state: `python3 scripts/hwdb_probe_u0.py run linux [--suspect NAME]`: `a1fw/regprobe_linux.c` (static musl, `/dev/mem` O_SYNC mmap, SIGBUS = external abort) over ssh.
- Suspect ranges (`SUSPECT`, plus `dmac`) run one per pass; blocked entries with `phase = "uboot"` apply to that state only; `--unblock NAME --only LO HI` tries one blocked range.

## Lint
- `python3 scripts/hwdb_lint.py [--by-file] [--all]`: lists hard-coded 0x18/19/1b/1c/48xxxxxx literals that match an hwdb entry. Report only.
- Context collisions exist (0x1c000000 is also the L2X S-channel table id).

## Ghidra round-trip (run on uboot-1 and the ubnt app, 2026-11-15, #69)
- Import: run `hwdb/gen/ghidra_import_hwdb.py` in a program: memory blocks for axi0 regions/blocks, labels per register, struct `<block>_regs` for dense blocks, function names + role comments from `hwdb/fw` for the binary matching the program name (or arg 1).
- Export: run `hwdb/gen/ghidra_export_hwdb.py [binary] [repo-root]`: writes non-default function names, sizes, function comments and EOL/PRE comments to `hwdb/fw/<binary>.toml`; keeps `role/regs/src/conf` of known addresses; new functions get `src = "ghidra <program> <date>"`, `conf = "I"`. Source: `scripts/ghidra/hwdb_export.py`.
- Ghidra is a consumer and contributor, not the store.
- Runner: `scripts/ghidra_pyrun.py` (PyGhidra venv `tmp/pgvenv`, setup in its docstring; `python -I`). `analyzeHeadless` has no Jython, `.py` scripts need PyGhidra.
- Flow per binary (project `tmp/ghidra/proj/<name>`, program `<name>.bin`; uboot1 = `full-flash.bin[0:447118]` at 0x1c000000, ubntapp = base 0x67030000):
  1. `analyzeHeadless ... -import` (raw ARM:LE:32:v7 + base), 2. `ghidra_import_hwdb.py`, 3. `scripts/ghidra/find_funcs.py lo hi` (push-prologue scan, `cmp r2` entry fix; auto-analysis misses table-reached functions),
  4. `ExportAll.java` + `scripts/ghidra_func_regs.py <name>` (registers per function), 5. `scripts/ghidra/apply_names.py names.tsv lo hi` (comment `[C|I] role @regs a.B,c.D`), 6. `hwdb_export.py` parses the tag into `role/conf/regs`.
  - `regs` accept `block.REG` or a block name only (`hwdb.py check`).

## Port map
- `hwdb/board/ports.toml` is the source; `scripts/us48_portmap.py [switchdrvr]` verifies the FastPath table (VA 0x1d8ecb4) and the OpenBCM p2l rule against it.
- Regenerate the docs table: `python3 scripts/hwdb_gen.py ports`.
