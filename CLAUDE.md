# CLAUDE.md — awto-unifi-us48

Mainline Linux port + RE for the UniFi US-48-500W. OpenWrt is parked (Dan 2026-11-15): target native mainline (`scripts/build_mainline.py`, `mainline/`); OpenWrt resumes later (parking issue lists what to reopen). **Public repo** — no secret values (filesystem paths + device IDs are fine), no backups/firmware images. SDK source + derived register tables ARE fine to commit (Dan 2026-10-14).

- Entry point `scripts/dev.py` (`describe` lists every command; `doctor`, `console`, `send`, `boot-ram`, `flash-net`, `boot-flash`). Console = one visible tio window; scripts use its socket, never the tty. Adapter is local on Selwyn since 2026-11-14 (leave `US48_HOST` unset; set `US48_HOST=lizard` only if it moves back).
- Build: `python3 scripts/build_mainline.py` (kernel + modules: Fedora `arm-linux-gnu-gcc`; rootfs `mainline/rootfs/` via `scripts/build_rootfs.py`: busybox + dropbear, static musl). No OpenWrt in the image path; `openwrt/` + `scripts/build_openwrt.py` are parked. Details: `docs/mainline.md`.
- Source trees from machine-shared stores, never fresh clones (#45): `tmp/linux-mainline` = worktree of the Linux store (`tmp/linux-store`); OpenWrt downloads + ccache shared (`tmp/openwrt-dl`, `tmp/ccache-openwrt`). All gitignored symlinks into `/mnt/1tnvme/git-mirrors`; never `git gc` in a store.
- Facts in `docs/`; findings + open questions in GitHub issues. Hardware facts (addresses, registers, ports, firmware functions) live in `hwdb/` (schema `docs/hwdb.md`); generated headers/tables, never copy by hand.
- Device: dev/test unit (it powered 5 PoE cameras on stock; not the house uplink, Dan 2026-11-16; Dan says still test), recovery via serial + JTAG, full-flash backups. Test images go in backup slot `kernel0` (`scripts/dev.py flash-kernel0` / `boot-flash`). Never write `kernel1` (stock), the bootsel record (`0x1ee0000`), `u-boot`, `EEPROM`; never `saveenv`; don't guess GPIO/I2C/SPI writes. u-boot-env: only the docs/autochain.md image (Dan 2026-11-15).
- Fans: presets only (50/70/90/100 %), no tach, no off. Quiet rule default (Dan 2026-11-16), 100 % switchable (`US48_FAN_BOOT_LEVEL`, `us48_fan.level`/`quiet`), see `docs/fan.md`; drivers `kernel/us48-fan` + awto-uboot `fan.c` — watch temperature on every boot. PoE is off at boot (`us48-poe-off`).
- Backups + stock firmware images stay out of git under `tmp/` or `private/`.
